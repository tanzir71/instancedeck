Questions about accounts, data and trust

Plain answers, with links to the details.

This project is in development. Guided Claude sign-in and custom-app editing are implemented. Real account, native pinning and hardware verification remain pending; check each guide's current limitations.
Is InstanceDeck free?

Yes. It is free and open source under the MIT license.

Read more

Does it modify Claude, Codex or other apps?

No. InstanceDeck launches the official app with different launch settings and data folders. Nothing is patched, copied or repackaged, so the app's own updates keep working.

Read more

Can I run two Claude Desktop accounts at the same time?

Yes. Each profile signs in once using the guided sign-in, then stays signed in. Your main Claude keeps working as before.

Read more

Is this allowed by the apps’ terms?

InstanceDeck is meant for keeping accounts you own separate, such as work and personal. Do not use it to share accounts or to get around usage limits. Check each provider's terms for your situation. This is not legal advice.

Read more

Where is my data stored?

On your PC, in a folder you choose. The default is %LOCALAPPDATA%\InstanceDeck\Profiles. Nothing is uploaded.

Read more

Why does Windows show a SmartScreen warning?

InstanceDeck releases are unsigned, so Windows may warn or block installation. Verify the source and published SHA-256 checksums, and review the code signing policy before installing.

Read more

Which apps are supported?

See the Apps directory. Each recipe shows its status and the versions it was tested on. Apps that accept a separate data path can be configured with a custom recipe.

Read more

Does it work on Mac?

Not yet. InstanceDeck is Windows-only.

Read more

Is InstanceDeck affiliated with Anthropic or OpenAI?

No. It is an independent open-source project. Product names identify compatibility; they do not imply endorsement.
