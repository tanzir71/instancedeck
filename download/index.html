Requirements

Windows 10 22H2 or later, or Windows 11. x64 and ARM64 packages are built in CI; manual hardware verification remains pending. Install Microsoft Edge WebView2 Runtime and the official target apps separately.

Signing and SmartScreen

Releases are unsigned. Windows may warn or block installation. Check the source and SHA-256 checksum; do not disable Windows protection to install an untrusted file.

Verify integrity

Download the checksum file from the same release, then compare it with PowerShell's result:

Get-FileHash -Algorithm SHA256 -LiteralPath '.\your-downloaded-file.exe'
