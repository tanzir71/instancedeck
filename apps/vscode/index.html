App compatibility

Run multiple instances of Visual Studio Code on Windows

InstanceDeck launches the installed Visual Studio Code executable with a separate data directory. The recipe uses app launch settings and leaves binaries untouched. Verify each visible account and data path before use.

Community

Recipe version 1. Reported test evidence below is not a guarantee for a different app version or Windows installation.

Reported versions and provenance

No app/Windows version has been verified yet.

How InstanceDeck isolates Visual Studio Code

--user-data-dir={profile}\data
--extensions-dir={profile}\extensions

{profile} means that profile's own data folder. {exeDir} is the currently discovered installation folder. A trailing ? marks an optional executable-path environment value.

Launch strategies: direct. Target binaries are left untouched.

Set up a profile

  1. Install the official Visual Studio Code app for your Windows user.
  2. Create a profile in InstanceDeck and choose its data location.
  3. Launch it, complete the app's supported sign-in flow and verify the visible account.

Known limitations

  • Local two-instance and account smoke testing is deferred; this Community recipe has not been verified on this machine.
  • Portable data folders can override these flags. Remote extensions and external tools may use their own shared state.
