Getting started

  1. Install the official app you want to use. InstanceDeck does not distribute it.
  2. Check its compatibility entry and reported limitations.
  3. Create a named profile in InstanceDeck and choose its parent data folder.
  4. Launch it and sign in through the official app. Check which account it shows.

The current build is in development. Guided Claude sign-in has automated crash coverage; real account verification remains pending. Windows shortcuts, hotkeys, the switcher and window identity are implemented; actual pinning still needs manual verification. Custom recipes, metadata import/export, optional Codex sessions sharing and dark theme are implemented. Update installation has not shipped yet. A preference or Storybook view does not imply that its later-phase engine is available.

Troubleshooting

If an app is not found, install it for the current Windows user and refresh Apps. If a profile opens the wrong account, stop using that profile and run its manual account health check. Do not copy authentication files between profiles.

Diagnostics shows the resolved launch plan and recent local launcher logs. Use its redaction option before sharing a report. An unknown Claude data layout must stop the guided sign-in rather than guess a path.
