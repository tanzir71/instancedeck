# InstanceDeck v0.1.0 — unsigned development preview

Launch official installed apps with separate profile data paths. Includes the
Windows desktop manager and CLI, eight Community recipes, guided journaled
Claude sign-in/recovery, profile shortcuts and icons, window identity, tray,
hotkeys/switcher, custom app configuration, metadata import/export, optional
Codex sessions sharing, dark theme and consent-gated update support.

Windows executables and per-user NSIS installers are unsigned. Portable archives
are available for x64 and ARM64. SHA-256 checksums and build reports accompany
the packages. Updater integrity signatures verify project artifacts and their
version; they do not make the Windows publisher trusted.

This is an unsigned development preview. Visible-account isolation, real sign-in
and recovery, taskbar pin/relaunch, tray/startup behavior, Windows 10, installer
execution and native ARM64 hardware checks remain manual. All recipes stay
Community. Callbackless/protocol-broker and DWM-border experiments are disabled.
Cowork VM sharing is not claimed.

Requires the official target apps and WebView2 Runtime to be installed
separately. Profiles are not a security sandbox. No target app binaries are
included or modified, no credentials are inspected and no telemetry is
collected.
